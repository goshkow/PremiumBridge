PremiumBridge is a smarter premium session manager for offline-mode Minecraft Java servers.

The backend JAR is compatible with Minecraft Java 1.21.9-1.21.11, 26.1.x, and 26.2. An optional Velocity companion uses native modern forwarding so authenticated premium players keep their Mojang UUID, skins, and tab profile while offline players continue using AuthMe or OpeNLogin.

## Supported loaders

- Paper
- Purpur
- Spigot
- Other Bukkit-compatible forks

## Not supported

- Fabric
- Forge
- NeoForge
