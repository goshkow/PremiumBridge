PremiumBridge — это умный менеджер premium-сессий для offline-mode серверов Minecraft Java.

Сборка ориентирована на Minecraft Java 26.1.2 и предназначена для серверов 26.1.x на Bukkit-совместимых лоадерах.

## Поддерживаемые лоадеры

- Paper
- Purpur
- Spigot
- Другие Bukkit-совместимые форки

## Не поддерживается

- Fabric
- Forge
- NeoForge
